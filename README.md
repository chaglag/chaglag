# Hi, I'm Chaitanya

I build **software that talks to machines**: local AI systems, and the glue code that makes
robots, cameras and PLCs do useful work.

- Industrial automation: cobot cells, TCP/Modbus/OPC-UA middleware, vision inspection
- Local-first AI: private, free-to-run assistants that run on my own laptop
- I ship small tools end to end: design, code, tests, docs, packaging

## Featured projects

| Project | What it is | Stack |
|---|---|---|
| **aimux** | Middleware that routes tasks to the AI desktop apps you are already logged into, no API keys. | Python, pywinauto |

## What I care about

Safe automation (approvals, audit trails, kill switches), tests that catch real bugs
(most of mine were found by running against real hardware or models, not mocks), and docs that
let the next person pick it up.
